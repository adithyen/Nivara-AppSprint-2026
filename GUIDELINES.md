# 📋 AppSprint Solution Challenge 2025 Guidelines

## Overview

Welcome to AppSprint Solution Challenge 2025!

This is a 15-day virtual mobile application development hackathon organized by the App Development IG, muLearn LBSITW.

Participants are expected to design and build a mobile application that solves a real-world problem.

---

# Eligibility

- Open to all students.
- Individual and team participation allowed.
- Teams may contain 2–4 members.
- A participant can belong to only one team.

---

# Technology

Flutter is the recommended framework.

However, participants are free to use any mobile development framework such as:

- Flutter
- React Native
- Kotlin
- Swift
- Ionic
- Expo

---

# Challenge Tracks

- EduTech
- HealthTech
- CivicTech
- AgriTech / LocalTech
- Open Innovation

---

# Repository Requirements

Every submission must contain:

- Public GitHub Repository
- README (using README_TEMPLATE.md)
- Screenshots
- Demo Video
- APK
- Presentation

---

# GitHub Requirements

Participants should:

- Fork this repository
- Commit regularly
- Keep the repository public
- Use meaningful commit messages

---

# Submission Requirements

Submit:

- Repository Link
- APK
- Demo Video
- Presentation
- Submission Form

---

# Judging Criteria

| Category | Points |
|-----------|---------|
| Problem Relevance | 20 |
| Innovation | 20 |
| Technical Execution | 25 |
| UI/UX | 15 |
| GitHub Activity | 10 |
| Demo | 10 |

---

# Bonus Points

- Accessibility
- Offline Support
- Play Store Deployment

---

# Plagiarism Policy

Projects must be original.

Using open-source libraries is allowed.

Copying another team's project will result in disqualification.

---

# AI Usage

Using AI tools like ChatGPT, Gemini, Claude, GitHub Copilot, Cursor, etc. is allowed.

Participants should understand the code they submit.

Judges may ask implementation questions.

---

# Code Ownership

Participants retain ownership of their projects.

The organizers may showcase projects for educational purposes with proper attribution.

---

# Code of Conduct

Respect all participants.

Harassment, discrimination, or offensive behaviour will not be tolerated.

---

# Organizer Decisions

The organizers' decision will be final.
