# 📘 **AppSprint Solution Challenge 2026** 

## **Participant Handbook** 

**Organized by:** App Development IG · muLearn LBSITW 

# **Welcome** 

#### Welcome to **AppSprint Solution Challenge 2026** ! 

We're excited to have you join this **15-day virtual mobile application development hackathon** . Whether you're building your first app or already have development experience, this challenge is designed to help you learn, collaborate, and create something meaningful. 

Throughout the challenge, you'll work individually or as a team to design and develop a mobile application that solves a real-world problem. By the end of the hackathon, you'll have a complete project, a polished GitHub repository, and valuable experience using modern development tools and workflows. 

We encourage you to experiment, learn from one another, and most importantly—enjoy the journey. 

# **About the Challenge** 

AppSprint Solution Challenge 2025 is a student-focused hackathon that encourages participants to build innovative mobile applications capable of solving real-world problems. 

The challenge emphasizes: 

- Problem-solving 

- Mobile application development 

- Team collaboration 

- Git & GitHub best practices 

- Project documentation 

- Presentation skills 

Flutter will be the framework demonstrated during workshops, but participants are welcome to use any mobile development framework they are comfortable with. 

# **Challenge Duration** 

**Duration:** 15 Days 

During these 15 days you are expected to: 

- Plan your idea 

- Design the application 

- Develop the application 

- Test your solution 

- Prepare documentation 

- Record a demo video 

- Submit your project 

Avoid waiting until the last day to complete your work. Consistent progress and regular commits are strongly encouraged.

# **Getting Started** 

## **Step 1** 

Register for the hackathon using the official registration form. 

## **Step 2** 

Fork the official GitHub repository. 

<u>AppSprint-2026</u> 

Forking creates your own copy of the repository where you will develop your project. 

## **Step 3** 

Clone your fork to your computer. 

Note : you should clone the repo that you forked not the original repo 

Example: 

git clone https://github.com/YOUR_USERNAME/AppSprint-2026.git 

## **Step 4** 

Create your mobile application inside your repository. 

Flutter example: 

flutter create my_app 

React Native example: 

npx create-expo-app my_app 

If you are using another framework, initialize the project following its official documentation. 

# **Understanding GitHub** 

Every participant should understand these basic GitHub concepts. 

### **Repository** 

Your project's home. 

### **Fork** 

Creates your personal copy of the official repository. 

### **Clone** 

Downloads the repository to your computer. 

### **Commit** 

Saves your progress. 

### **Push** 

Uploads your commits to GitHub. 

### **Release** 

Used to upload your final APK for judging. 

# **Daily Workflow** 

We recommend following this workflow every day. 

1. Plan today's tasks. 

2. Build a feature. 

3. Test the feature. 

4. Commit your changes. 

5. Push to GitHub. 

Good commit messages include: 

- Add login screen 

- Implement Firebase authentication 

- Fix profile page layout 

- Add dark mode support 

Avoid commit messages like: 

- update 

- final 

- test 

- changes

# **Rules** 

Participants must: 

- Build a genuine mobile application. 

- Keep their repository public. 

- Maintain regular GitHub commits. 

- Submit all required deliverables before the deadline. 

- Respect fellow participants. 

# **Prohibited Activities** 

Participants **must not** : 

- Submit applications developed before the official hackathon start date. 

- Present pre-built templates or existing projects as original work. 

- Plagiarize another team's code, design, or ideas. 

- Share confidential API keys, passwords, or secrets in their repository. 

- Submit private repositories that judges cannot access. 

- Engage in any form of cheating or unfair collaboration. 

Violation of these rules may result in score deductions or disqualification.
