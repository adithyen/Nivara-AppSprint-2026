# Flutter Setup Guide

## Install Flutter
1. Download Flutter SDK: https://flutter.dev/docs/get-started/install
2. Add Flutter to PATH
3. Run: flutter doctor
4. Fix any issues shown

## Recommended VS Code Extensions
- Flutter
- Dart
- Error Lens
- Pubspec Assist

## First App
```bash
flutter create my_app
cd my_app
flutter run
```
